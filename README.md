## 📐 Overview & Layout Architecture

This project features a multi-section financial portal layout designed for optimal navigation and digital user experience:

| Section | Key Features & Functionality |
| :--- | :--- |
| **Top Utility Bar** | Quick audience toggle (Personal, Business, Islamic Banking) and 24/7 hotline details |
| **Navigation Header** | Sticky glassmorphism navbar with deep links and portal action triggers |
| **Hero Portal Canvas** | Dynamic brand headline, trust badges, and quick login access cards |
| **Product Showcase** | Tiered account options (Checking, High Yield, Wealth) and loan APR cards |
| **Interactive Modals** | Zero-JS pure CSS `:target` modal dialogs for Login, Account Opening, and Password Reset |

---

## ✨ Features

* 🔒 **CSS-Only Modal Architecture:** Uses CSS `:target` pseudo-classes for light-weight modal popups (Login, Signup, Reset) without relying on JS frameworks.
* 💳 **Interactive Card Showcase:** Custom visual components for credit card products, security badges, and banking perks.
* 🎨 **Enterprise Glassmorphism Theme:** Dark primary aesthetics combined with subtle gradient layers, glass overlay effects, and custom CSS variables.
* 📱 **Fully Responsive Layout:** Optimized CSS Grid and Flexbox structures adapt seamlessly across desktop, tablet, and mobile displays.
